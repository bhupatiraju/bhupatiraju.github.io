# Width Variants

To compare different width options, edit the stylesheet link in `index.html`:

## Current (Enhanced 900px)
```html
<link rel="stylesheet" href="styles-enhanced.css">
```
**900px max-width** - Good balance, modern feel

## Original (750px)
```html
<link rel="stylesheet" href="styles.css">
```
**750px max-width** - Very narrow, optimal reading but feels cramped

## Wide (1000px)
```html
<link rel="stylesheet" href="styles-1000px.css">
```
**1000px max-width** - Wider, more spacious

## How to Switch
1. Open `index.html`
2. Find line 7: `<link rel="stylesheet" href="...">`
3. Change the href to one of the CSS files above
4. Refresh your browser

Currently using: **styles-enhanced.css (900px)**
